# Competitor teardown

Self-contained reference for `str-ux-research` Step 6. The point is not to list what competitors
have. It is to find the claim nobody in the set is making, and the standard the client has to
clear to be considered.

## Choosing the set

Three to five, chosen by who the client actually loses deals to. Ask the client directly, and
cross-check against the sites that rank for the client's money queries. The biggest name in the
sector is only in the set if real buyers compare the client to it.

Include one adjacent alternative that is not a direct competitor. For most businesses the real
competitor is doing nothing, using a spreadsheet, or handling it in-house. That option needs a
row too.

## Method

For each, capture the home page and the one page that carries the conversion. Use
`tool-firecrawl-scraper` or WebFetch. Note the date you looked, because competitor sites change.

Run the five-second test on each competitor home page as well as the client's. It is the fastest
way to see who is clear and who is vague.

## The table

| Dimension | What to record |
|-----------|----------------|
| Promise above the fold | The literal headline, quoted |
| Who it says it is for | Named audience, or blank if they do not say |
| Proof used | Reviews, named case studies, numbers, logos, credentials, guarantees |
| Primary conversion action | What the main button does, and the commitment it asks for |
| Secondary action | What they offer someone not ready. Blank is common and is an opening |
| Pricing transparency | Published, indicative, or hidden behind a call |
| Content depth | Do they answer buying questions, or only sell |
| Trust and risk reversal | Guarantee, insurance, accreditation, named people with faces |
| Five-second test | Who, what, next. Pass or fail each |
| The one thing they do better | Single sentence, honest |

## What comes out of it

**The category baseline.** What every competitor does, which the client must match or explicitly
reject. Matching the baseline wins nothing. Falling below it loses deals before the pitch.

**The positioning gap.** One sentence naming what nobody in the set is claiming, that the client
can credibly claim. Cross-check it against `brand_context/positioning.md`. If they disagree,
flag it back to `mkt-positioning` rather than silently overriding the angle.

**The proof gap.** What competitors prove that the client currently cannot. This becomes an
asset request in the brief, for example named case studies, review volume, or named staff with
photographs.

**Conversion mechanics worth copying.** Where a competitor offers a lower-commitment second
action and the client does not, that is a concrete recommendation, not an observation.

## What not to do

Do not benchmark on traffic estimates from third-party tools and present them as fact. If a
traffic number goes into the brief, it names the tool and the date, and it is labelled an
estimate.

Do not copy a competitor's structure because it looks polished. A competitor's page order
reflects their audience and their evidence, not the client's.

Do not rank competitors on aesthetics. Rank them on clarity, proof and conversion path.
