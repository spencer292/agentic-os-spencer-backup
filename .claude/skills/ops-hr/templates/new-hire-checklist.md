# New Hire Checklist — {Name} — start date {YYYY-MM-DD}

Deadlines here are legal, not administrative. Each one has a date, not a "soon".

## Hard deadlines
| Item | Deadline | Done |
|---|---|---|
| **I-9 Section 1** — employee completes | On or before the first day of work | [ ] |
| **I-9 Section 2** — employer examines original documents | Within **3 business days** of the start date | [ ] |
| **WA new-hire reporting** | Within **20 days** of hire (confirm the payroll provider does this — get it in writing) | [ ] |
| Added to L&I quarterly reporting at the correct risk class code | Before the first quarter close | [ ] |
| PFML / WA Cares withholding started | First pay run | [ ] |

I-9 and its supporting documents are filed in `hr-private/i9/{name}/` — **separate from the personnel
file**, as the rule requires.

## Paperwork to collect (all to `hr-private/`, never to the repo)
- [ ] W-4
- [ ] Direct deposit authorisation
- [ ] Emergency contact
- [ ] Driving record consent, then MVR run — record only the *decision* in the personnel file
- [ ] Background check consent (post-qualification only), then run

## To give them, in writing
- [ ] Signed offer letter (copy to personnel file)
- [ ] Employee handbook plus signed acknowledgement
- [ ] **Paid sick leave policy** and how balances are reported — monthly balance notice is required
- [ ] PFML notice
- [ ] **Accident Prevention Program** and a documented safety orientation
- [ ] Required posters — physical at the shop and digital copies to a field crew

## Systems and equipment
- [ ] Jobber user created, correct permissions
- [ ] OptimoRoute driver created
- [ ] Company email and phone
- [ ] Vehicle assigned, insurer notified, fuel card
- [ ] Phone, uniform, trap inventory issued — **log serial numbers and counts.** This list is exactly
      what gets recovered at separation, and it is worthless if it was never written down
- [ ] Added to the territory map and route assignment

## Day one
- [ ] Introduced to the crew, and to who they call for what
- [ ] The promise Got Moles makes to customers, and how they are judged (training Module 0)
- [ ] Safety orientation delivered and signed
- [ ] Training program started — `projects/briefs/technician-training-program/`

## Day 90
- [ ] Paid sick leave becomes usable
- [ ] Competency sign-off gate — solo route, or not
- [ ] First formal review
