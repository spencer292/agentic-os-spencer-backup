## Session 1 — Codex CLI review harness

### Goal
Install the OpenAI Codex CLI on this machine so Codex can act as an independent
second reviewer of Claude's work.

### Deliverables
- `~/.codex/AGENTS.md` — Codex's global instruction file (outside the repo, so
  `git pull` can never touch it). Mirrors the `CLAUDE.local.md` rules Codex cannot
  see: US English, no I-713 claims, claims guardrails, mole-disposal wording,
  chemical-free-first positioning, the full residential pricing table + Cory owning
  all bids, shipped-file / no-deploy / never-push-to-origin safety, and the
  Jobber/OptimoRoute sharp edges (SYNC unschedules, notes are oldest-first,
  CallRail key read-only).
- `.claude/commands/codex-check.md` — `/codex-check` slash command. Runs Codex
  against the working tree, then Claude verifies and triages each finding
  (confirmed / already handled / wrong / style) instead of relaying raw output.
  Review-only: no Edit/Write in `allowed-tools`.
- `CLAUDE.local.md` — new `## Local Commands` table registering `/codex-check`
  (gitignored, so not in the commit).

### Decisions
- **Codex reads `AGENTS.md` natively** — that is why no wrapper was needed. The
  gap was `CLAUDE.md`/`CLAUDE.local.md`, which Codex never reads.
- **Bridge lives at `~/.codex/AGENTS.md`, not in the repo.** A repo-root
  `AGENTS.md` is a shipped file and must not be edited on this install; the global
  file is user-owned and pull-proof. **Cost: the two must be synced by hand when a
  `CLAUDE.local.md` rule changes.**
- **`/codex-check` is review-only by design.** Keeps "what a second reviewer
  thinks" and "what we changed because of it" as two separate approved steps.
- **Auth via `codex login` (ChatGPT OAuth)**, not the API key — though
  `--api-key` against the existing `OPENAI_API_KEY` remains the fallback if the
  Amex limit makes another subscription awkward.

### Verification — smoke test found 3 things, only 1 of them Codex's win

  `ssc-template-builder.md` as an invalid alias. It is valid in this Claude Code
  version, both agents registered fine, and it is the deliberate 2026-07-26

Independently corroborated by session `9b5457a3`: Codex flagged `model: fable` as an invalid alias, was wrong, and both agents registered fine.
