### Decisions
- **Capture surface = phone web app**, not dictating into Jobber with a background rewrite. The tech confirms the formatted note on screen before anything is written; these notes drive real follow-up scheduling, so an unsupervised rewrite of a customer record was not worth the convenience.
- **Formatter is gated on the existing `parse-note.mjs`** — the Worker imports the *same* parser the report sync and scheduling engine use, rather than copying the grammar. A voice note that the downstream automation cannot read fails in the yard, not silently a week later.
- **Gemini, not OpenAI.** This install's `OPENAI_API_KEY` returns 429 insufficient_quota on every call. `gemini-3.6-flash` takes audio natively and covers both steps.
- **No client-side audio conversion.** Verified Gemini accepts webm/mp4/ogg/aac/wav, so the phone ships its native format. Opus is ~23 KB vs ~306 KB WAV for the same clip — matters on rural properties.
- **Two model calls, not one** — the verbatim transcript is kept and logged so a bad note traces to either mishearing or misformatting.
- **Pilot = Spencer first**, on his own route.

### Findings
- **Typed notes are leakier than they look.** Across 4,341 real notes from 10 days: misses parse on only **56%**, moles on **72%** — usually the line is simply absent. The app prompts for the missing field before send, which is the direct fix for the "nonconforming notes fail silently" gap raised 2026-07-10.
- **`jobCreateNote(jobId: EncodedId!, input: JobCreateNoteInput!)` works** — proven live on #8056 Madera West, then removed. `jobDeleteNote` input arg is **`noteId`, not `id`**.
- **`JobNote.createdBy` returns `Application`** for API-written notes — there is no author field on the input, so notes are NOT attributed to the technician in Jobber's UI.
- **`parse-note.mjs` drops the compass placements** — `froh`/`floh`/`broh`/`bloh` are in live use (87 occurrences in 10 days) but its `POS` map only knows foh/boh/loh/roh. Counts and trap types still parse. Left alone deliberately: that file drives live scheduling.
- Spencer had **Sunday visits booked 2026-08-02 and 2026-08-09** (2 each) — the weekend-defect pattern `weekend-sweep.mjs` exists to catch.
