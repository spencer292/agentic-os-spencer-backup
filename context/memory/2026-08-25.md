## Session 3

### Project
syperformance-redesign

### Goal
Phase 4 — product page templates (in-house hero shell + resold simplified shell), taken out of order because Phase 2's build and Phase 3's data half are both blocked on the Admin token.

### Deliverables
- `theme/snippets/syp-product-flags.liquid` — single definition of "is this made in-house"; returns a pipe-delimited string because Liquid `render` is scope-isolated
- `theme/snippets/syp-in-house-handles.liquid` — GENERATED fallback list (110 in-house handles), regenerate with `scripts/gen-product-flags.mjs`
- `theme/scripts/gen-product-flags.mjs` (in `scripts/`) — generator; excludes the 51 unclassified so they render as resold
- `theme/blocks/syp-product-identity.liquid` — MADE IN-HOUSE badge + brand + part no., placed in the buy column above the title
- `theme/sections/syp-product-detail.liquid` — fitment, rating/lead time, why-this-part, specs, before-you-buy, warranty, install, complete-the-build
- `theme/assets/syp-product.css`
- `theme/templates/product.json` — wired both; removed Horizon's algorithmic product-recommendations
- Commit `5af5601`

### Decisions
- **One branching template, not two.** Per-product `templateSuffix` needs Admin API writes across 198 products; a branch needs nothing and cannot strand a product on the wrong shell.
- **Never infer in-house from `vendor`.** Metafield first, generated audit list second, no third guess. The 51 unclassified render as resold — an unearned MADE IN-HOUSE is worse than no badge.
- **Suppress known-bad vendor on resold parts.** A resold product whose vendor is one of the four house spellings shows no brand rather than printing "SYPERFORMANCE" on an AEM pump.
- **Identity badge lives in the buy column**, not in the detail section — the section starts below the fold on a six-image product.
- **Missing required content warns in `request.design_mode` only.** Customers never see scaffolding; the page builder can't miss it.
- **Cross-sell is curated metafield only.** Horizon's algorithmic recommendations removed — the plan says cross-sell by what the part requires, not "customers also bought". Consequence: no cross-sell at all until the metafield is populated.
- Section renders nothing when it has no content, rather than an empty dark band.

### Open threads
- Still blocked on the Shopify Admin token (see Session 2). Phase 4 content — why-this-part, before-you-buy, specs, HP ratings, lead times — is all metafield-driven and empty until Phase 3.
- **Warranty text is deliberately blank.** Spencer has to supply real terms; the section shows an editor warning rather than a placeholder.
- 51 products still need Spencer's in-house/resold call in `data/unknowns-review.csv` (`ownerDecision` column empty). The audit flagged this as gating Phase 4 and it still does.
- Product photography: white-background shots read as bright rectangles on the dark palette. Still unaddressed.
