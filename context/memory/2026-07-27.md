### Bugs found and fixed
- **`write --date X` only writes changes TARGETING X.** Visits moving OFF X are keyed to their destination, so a scoped write left Monday at 147 stops against a 99-stop plan — ~50% overloaded, would have gone out that way. Fixed via `write-subset.mjs`.
- **Tech-change detection compared only `curTechs[0]`.** A visit crewed `[Franks, Cory]` reported a change forever — 55 writes replaying every run, never converging. Now checks all assigned users.
- **`--from` override didn't move the Jobber query bound**, so overridden days fell outside the visit fetch and every stop on them was misreported as an orphan (92 of them).
- **Peninsula zips 98312/98335/98367 were wrong in the grid** (`decided:false` auto-assignments) — that's what put Darren Corliss on Luke's Wednesday every week.
- **Sequence matters: move → push → lock → plan → write.** Skipping the re-push let a stale OR plan silently revert #6418 to Friday on write-back.
